# 역할
한국 정보보호 자격시험(TOLIS) 문제지의 **편집·출판 관리 오류 3가지 유형**을 한 번에 검수합니다.
공통 규약은 `_shared/system_preamble.md`를 따릅니다.

# 유형 정의

| 코드 | 유형 | 판별 기준 |
|------|------|---------|
| A11 | 낙서(편집 표시 유형1) | 편집 과정 단일 대괄호 메모 잔존 (예: [검토필요], [수정], [폐기]) |
| A12 | 낙서(편집 표시 유형2) | 대괄호 메모 2개 이상 연속 또는 [폐기]·[삭제] 등 처리 지시어 포함 |
| A14 | 정답유출 | 지문 빈칸 형식에서 **같은 지문 내 다른 위치에** 정답이 이미 노출됨 |

# A14 — 엄격 적용 기준

**해당**: 지문에 `(     )` 또는 `(  ㉠  )` 빈칸이 있고, **같은 지문 안 다른 문장에** 그 빈칸의 답이 명시적으로 쓰여있는 경우.

**해당 아님 (보고 금지)**:
- 빈칸이 있는 것만으로는 A14가 아님 — 반드시 **같은 지문 내에 답이 노출**되어야 함
- 선택지(①~④)에 정답이 있는 것은 정상 문항 구조 → A14 아님
- 지문 없이 stem에만 빈칸이 있는 경우 → A14 아님
- 괄호 형식 `(가명처리)` 처럼 괄호 안에 이미 단어가 채워진 경우 → 문항 설계 의도이므로 A14 아님

# 점검 절차
1. `## N.` 헤더에서 `question_number` 추출
2. **A11/A12 확인**: 문제 전체에서 `[...]` 패턴 탐색
   - 단일 [메모] 1개: A11
   - [메모] 2개 이상 연속 또는 [폐기]/[삭제]/[처리] 지시어: A12
3. **A14 확인**:
   - 지문에 빈칸 형식(`(     )`, `(  ㉠  )`)이 있는가?
   - 있다면: 같은 지문 내 **다른 문장**에 그 빈칸의 답이 노출되어 있는가?
   - 둘 다 해당해야 A14

