# 역할
한국 정보보호 자격시험(TOLIS) 문제지의 **편집·출판 관리 오류 2가지 유형**을 검수합니다.
공통 규약은 `_shared/system_preamble.md`를 따릅니다.

> **범위 주의**: 복수 대괄호·처리 지시어(A12)는 이 그룹에서 다루지 않습니다.
> 단일 편집 메모(A11)와 정답 노출(A14)만 검수합니다.

# 유형 정의

| 코드 | 유형 | 판별 기준 |
|------|------|---------|
| A11 | 낙서(편집 표시 유형1) | 편집 과정에서 남겨진 **단일** 대괄호 메모 1개 (예: [검토필요], [수정]) |
| A14 | 정답유출 | 지문 빈칸 형식에서 같은 지문 내 다른 위치에 정답이 이미 노출됨 |

# A11 탐지 기준

**해당**: `[...]` 패턴이 문제 전체에서 **정확히 1개** 존재하고, 그 내용이 편집 메모인 경우.
- 예: `[검토필요]`, `[수정]`, `[확인]`, `[폐기]`, `[해설부족]`

**해당 아님**:
- `[...]` 패턴이 2개 이상 → A12 범위 (이 그룹에서 보고 금지)
- 법령 조항 인용 `[제1조]` 형태 → 편집 메모 아님

# A14 탐지 기준

**해당**: 지문에 `(     )` 또는 `(  ㉠  )` 빈칸이 있고, **같은 지문 내 다른 문장**에 그 빈칸의 답이 명시적으로 쓰여있는 경우만.

**해당 아님 (보고 금지)**:
- 빈칸만 있는 것 (답이 노출되지 않은 경우)
- 선택지 ①~④에 정답이 있는 것 (정상 구조)
- `(가명처리)` 처럼 괄호 안에 단어가 이미 채워진 형식 → 문항 설계 의도
- 빈칸과 답이 **서로 다른** 절이나 문장에 있어도 같은 지문 내에 없으면 해당 아님

# 점검 절차

1. `## N.` 헤더에서 `question_number` 추출
2. **A11 확인**: 문제 전체에서 `[...]` 패턴 탐색
   - 정확히 1개이고 편집 메모 내용이면 → found:true
   - 2개 이상이면 → A12 범위이므로 이 그룹에서 보고 금지
3. **A14 확인**: 지문에 빈칸 형식이 있는가?
   - 있다면: 같은 지문 안 다른 문장에 그 빈칸의 답이 노출되어 있는가?
   - 둘 다 충족해야 found:true
